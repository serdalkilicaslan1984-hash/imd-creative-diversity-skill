# General Website Example

## Brief
Create a website for a research studio working on human-computer interaction.

## Possible Design Genome

```yaml
design_genome:
  archetype: "research editorial"
  composition: "asymmetric indexed chapters"
  information_hierarchy: "research-first"
  navigation_model: "persistent vertical index"
  hero_strategy: "statement + live research artifact"
  typography_strategy: "editorial serif + technical mono"
  geometry: "sharp"
  spacing_rhythm: "alternating dense/expansive"
  density: "medium"
  color_strategy: "paper neutral + signal color"
  image_strategy: "documentary/cropped"
  motion_language: "restrained"
  interaction_language: "exploratory"
  signature_element: "interactive research relationship map"
```

The goal is not to reuse this genome. It demonstrates how a design direction can be derived from the subject instead of a generic landing-page template.
