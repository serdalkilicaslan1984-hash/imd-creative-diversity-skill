# DeFi Example

## Brief
Design a cross-chain lending interface.

## Possible Web3 Genome

```yaml
web3_genome:
  domain: "defi"
  product_type: "cross-chain lending"
  chain_context: "persistent source/collateral context"
  wallet_context: "visible but compact"
  transaction_frequency: "high"
  transaction_ux: "explicit"
  data_density: "high"
  market_data_priority: "rates + collateral"
  risk_visibility: "very high"
  chart_language: "analytical"
  position_visibility: "persistent"
  approval_model: "explicit"
  network_switching: "guided"
  signature_element: "cross-chain collateral flow map"
```

The interface should make supplied assets, borrowed assets, rates, health factor, liquidation risk, network context, fees, and transaction consequences clear.

The signature element should explain the protocol rather than act as decoration.
