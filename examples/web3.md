# Web3 / NFT Example

## Brief
Create an interface for an on-chain generative art collection.

## Direction

Avoid the default neon NFT marketplace aesthetic.

A project-specific experience might use the generative rules of the collection themselves as the visual/navigation system.

Potential signature element:

**Trait Space Explorer** — users navigate the collection through relationships among generative traits rather than only a conventional card grid.

Important product information such as ownership, token ID, contract context, chain, traits, listings, offers, and transaction state should remain clear and usable.

Do not create fake scarcity, fake countdowns, fake sales, or misleading wallet prompts.
