# IMD Creative Diversity Skill

An experimental skill proposal for website-building AI agents, designed to reduce repetitive AI-generated layouts while preserving usability, accessibility, technical correctness, and the user's brief.

The skill adds a structured creative process before implementation:

**Brief → Concept Divergence → Design Genome → Signature Element → Build → Genericity Test → Self-Critique**

It also includes domain-specific guidance for **Web3, DeFi, trading, wallets, bridges, staking, lending, NFTs, DAOs, explorers, analytics, and other crypto products**.

## Why

Independent AI agents can still converge on the same visual patterns: centered heroes, repeated cards, bento grids, generic SaaS gradients, glass panels, and nearly identical section structures.

This proposal aims to make diversity **structural rather than cosmetic**.

Changing a color palette is not a new design. The skill encourages variation in information architecture, composition, hierarchy, navigation, content rhythm, interaction, typography, imagery, and motion.

## Core ideas

- Generate three materially different concepts before implementation.
- Define a project-specific **Design Genome**.
- Avoid generic AI patterns unless the brief genuinely calls for them.
- Require a meaningful **Signature Element** for substantial creative builds.
- Use agent/job identity as an optional deterministic diversity influence.
- Run a **Genericity Test** before delivery.
- Preserve accessibility, responsiveness, security, and usability.
- Optionally emit a lightweight **Design Fingerprint** for future network-level similarity checking.

## Web3 / DeFi

The Web3 section goes beyond visual styling. It includes UX guidance for transaction clarity, wallet/network state, token approvals, slippage, price impact, gas, routing, liquidation risk, health factor, APR/APY, PnL, bridges, trading interfaces, NFT flows, governance, and explorers.

It also explicitly avoids fabricated live-looking financial data and misleading transaction or wallet UX.

## Example Design Genome

```yaml
design_genome:
  archetype: "editorial technology"
  composition: "asymmetric chapter grid"
  navigation_model: "persistent vertical index"
  typography_strategy: "large grotesk display + restrained reading face"
  density: "medium-low"
  motion_language: "restrained directional transitions"
  signature_element: "interactive vertical project index"
```
